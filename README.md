# CraftNest Backend

CraftNest is a production-ready backend for a multi-vendor handmade marketplace where artisans can sell handmade products and customers can browse, purchase, and track orders.

## ✨ Features (Planned)

- User Authentication
- Seller Management
- Product Catalog
- Shopping Cart
- Order Management
- Product Reviews
- Search & Filtering
- Dockerized Development
- CI/CD with GitHub Actions

## 🛠️ Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Docker
- Redis (Planned)
- Celery (Planned)

## 📌 Project Status

🚧 Currently in active development.
